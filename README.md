# SOE Chainvote

Mobile-first private blockchain voting for the **Software Engineering Departmental Elections**, FUTO — **2025/2026 session**.

**Live booth (no extra server):** [https://4minu.github.io/Blockchain-Based-Electronic-voting-system/](https://4minu.github.io/Blockchain-Based-Electronic-voting-system/)

The phone APK and that page are the same self-contained booth. Login, ballots and the BFT hash chain run in the browser / on the device. They do **not** call a remote API.

Presidential slate: **Garba Aminu** and **Ugwumba Akachukwu Mac-Anointed**.

## Sign in

Use the FUTO email on the class list **or** the student name, plus the registration number.

Examples that open the booth for Garba Aminu:

- `Garba Aminu` / `20211288832`
- `garbaaminu.20211288832@futo.edu.ng` / `2021/1288832`

## Android APK

1. Uninstall any older SOE Chainvote.
2. Download `SOE-Chainvote.apk` from [Releases](https://github.com/4minu/Blockchain-Based-Electronic-voting-system/releases).
3. Allow install from this source, then open the APK.
4. Sign in. The class roll is bundled in the app — airplane mode still works.
